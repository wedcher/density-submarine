今日上課版：更新 Google 收件服務

學生只使用 GitHub 的一個遊戲頁面。Google 後端改用試算表，提供投稿、同學清單與關卡讀取。本頁不會代替你部署。

  1. 在 Apps Script 的「程式碼.gs」全選貼入完整 Code.gs，儲存。這版沿用已記錄的試算表，尚未設定才自動建立；不必修改資料夾或試算表 ID，不會清空舊工作表。
  2. 這版已把背景資料連線包含在 Code.gs；原本的 Index.html 可以保留，不必替換或刪除。
  3. 「部署 → 管理部署作業 → 鉛筆 → 新版本 → 部署」。保留「以我執行」、「所有人可存取」，依畫面重新允許試算表權限。
  4. 回到原本 GitHub 遊戲重新整理。首頁同學關卡區不應再顯示連線錯誤。
  5. 用無痕視窗設計簡單關卡、試玩通關、填暱稱投稿，再用另一個視窗重新整理清單並遊玩；在你的雲端硬碟搜尋「密度小艇投稿（試算表）」確認資料。

上面步驟完成前：Google 真實收件、匿名存取與另一人線上遊玩均為待使用者驗收。舊 Drive JSON 不會自動搬入試算表。
