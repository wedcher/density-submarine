# 教師管理設定

1. 將目前 main 分支的完整 Code.gs 貼入原 Apps Script 專案並儲存。
2. 在專案設定顯示 appsscript.json，若有 oauthScopes 清單，加入 https://www.googleapis.com/auth/userinfo.email，保留原本試算表權限。儲存後依 Google 畫面重新授權。
3. 更新原公開部署的新版本，執行身分維持「我」，存取權維持「所有人」。
4. 另外建立「教師管理」網頁應用程式部署，執行身分選「我」，誰可以存取選「只有自己」。管理網址為這個新部署的 /exec 網址加上 ?admin=1。
5. 用部署者帳號開啟管理網址，填入這個教師專用網址並儲存設定。學生首頁之後載入清單即可取得教師入口。
6. 先保留按讚開啟供體驗，需要時在管理頁關閉。隱藏關卡會立即禁止新的讀取及按讚，已開啟的遊戲畫面需重新整理才反映下架。
7. 檢查另一個帳號與無痕視窗無法管理，並確認隱藏／恢復／刪除及開關。每次後端升版都需要更新公開與教師兩個部署。

管理操作逐次檢查登入者與執行者帳號一致。未能取得身分時會拒絕操作。現有部署者已確認可進入教師頁並讀取投稿與縮圖。其他帳號與無痕存取需另行確認。

首頁縮圖與教師預覽使用關卡資料繪製，可放大。投稿直接公開。永久刪除會同時清理按讚資料，刪除前會確認。

## 本專案部署紀錄（2026-11-09）

公開服務已更新第 7 版，教師專用服務已建立第 8 版。詳細網址與驗收紀錄見 PROJECT.md。按讚開關調整與投稿管理日常操作不需要重新部署。程式後端升版時，公開及教師兩個部署均須更新。
